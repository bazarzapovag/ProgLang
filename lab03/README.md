* **Тип в программировании** — характеристика данных, определяющая множество допустимых значений, операции над ними и способ хранения в памяти.
* **Статическая типизация** — типы проверяются на этапе компиляции; тип переменной фиксируется до выполнения программы.
* **Динамическая типизация** — типы проверяются во время выполнения; тип переменной определяется значением в момент присваивания.
* **Неявная типизация** — тип выводится компилятором/интерпретатором автоматически из контекста, без явного указания программистом.
* **Явное преобразование типа** — программист сам указывает операцию приведения типа (int(x), (float) y).
* **Неявное преобразование типа** — приведение выполняется автоматически средой выполнения/компилятором без указания программиста (например, int - float).
* **Сильная типизация** — язык запрещает операции над несовместимыми типами и не выполняет автоматических приведений, ведущих к потере смысла; требует явного преобразования.
* **Слабая типизация** — язык допускает операции над значениями разных типов и автоматически приводит их, даже если это ведёт к неожиданным результатам.

### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

Неявное преобразование выполняется автоматически компилятором, когда тип значения не совпадает с ожидаемым типом. Всегда действует правило: преобразование идёт от типа с меньшим «рангом» к типу с большим «рангом».

bool - char - short - int - long - long long - float - double - long double

**Преобразования при присваивании**

Выполняются, когда значение одного типа присваивается переменной другого типа.
Правило: правый операнд приводится к типу левого.
Если тип приёмника «шире» источника, то значение расширяется без потерь:
Если тип приёмника «уже» источника, то возможна потеря данных (усечение):
При приведении к bool: 0 - false, любое ненулевое - true.
При приведении целого к целому меньшего размера — берётся младшая часть

**Преобразования при арифметических действиях**

Применяются к операндам бинарных операций.

1. Целочисленное продвижение (integral promotion)

* Операнды типа **char**, **short**, **bool** и их беззнаковые версии приводятся минимум к **int** (если int вмещает все значения), иначе к **unsigned int**.

2. Обычные арифметические преобразования

* Операнды приводятся к «общему» типу по правилам:
1. Если один операнд long double — другой приводится к long double.
2. Иначе если один double — другой к double.
3. Иначе если один float — другой к float.
4. Иначе (оба целые) — применяются целочисленные продвижения, затем:
* Если типы совпадают — работа продолжается.
* Если оба знаковые или оба беззнаковые — меньший по рангу приводится к большему.
* Если знаковый может вместить все значения беззнакового — беззнаковый → знаковый.
* Иначе оба приводятся к беззнаковой версии типа знакового операнда.

**Преобразования с логическими значениями**

В bool: любой скалярный тип преобразуется неявно:
* числа 0, 0.0, '\0' - false;
* любое другое ненулевое значение - true.

Из bool: true - 1, false - 0 при преобразовании в целый или вещественный тип

Арифметические операции с bool: сначала выполняется целочисленное продвижение к int, поэтому bool участвует как 0 или 1.

Логические операторы &&, ||, ! — их операнды приводятся к bool по правилу «ненулевое - true». Результат имеет тип bool.
