### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

*Проверка отчета будет включать проверку знания правил.*

*Преобразования при присваивании*
При присваивании значение правого операнда приводится к типу левого операнда. Если типы несовместимы — либо ошибка компиляции, либо (для арифметических типов) преобразование с возможной потерей данных.

*Преобразования при арифметических действиях*
При бинарных арифметических операциях (+ - * / % & | ^ << >> < > <= >= == !=) операнды приводятся к общему типу в два шага.
* Шаг 1. Целочисленное расширение (integral promotion).
bool, char, signed char, unsigned char, short, unsigned short → int (если int вмещает все значения), иначе → unsigned int.
* Шаг 2. Приведение к общему типу.
long double → оба к long double.
иначе double → оба к double.
иначе float → оба к float.
иначе (оба целые) — по «рангу»: unsigned long long > long long > unsigned long > long > unsigned int > int.
Если один знаковый, другой беззнаковый того же ранга → знаковый приводится к беззнаковому.
Если беззнаковый старше — знаковый приводится к беззнаковому.
Если знаковый может вместить все значения беззнакового — беззнаковый приводится к знаковому.

*Преобразования с логическими значениями*
1. Логические операторы &&, ||, !
* Операнды приводятся к bool по правилу: 0/nullptr → false, иначе → true.
* Результат всегда имеет тип bool.
* Операторы && и || ленивые: правый операнд может не вычисляться.

2. Побитовые операторы &, |, ^, ~ с bool
Операнды bool проходят целочисленное расширение до int.
Результат — int

3. Сравнения
Результат операторов ==, !=, <, >, <=, >= — всегда bool

### Задание 6 **(2)**

Рассмотрите следующий фрагмент программы. 
```
int a = -1, b = 1;
unsigned int c = 1;
std::cout << a*b << std::endl;
std::cout << a*c << std::endl;
```
* *Объясните работу этой программы, используя правила неявного преобразования типов*
* a * b: оба int поэтому результат int = −1.
* a * c: a (int) и c (unsigned int). Unsigned int = 1 - 4294967295. Результат 4294967295 * 1 = 4294967295.
  
* *Что произойдет, если тип* **int** *заменить на* **short**, а **unsigned int** на **unsigned short**?*
* a и b short. По правилам integral promotion short расширяется до int. Поэтому результат -1.
* short и unsigned short расширяются до int, если int может вместить все значения unsigned short.
int (32 бита) вмещает все значения unsigned short (16 бит). Значит, оба операнда расширяются до int. Поэтому результат тоже -1.

### Задание 7 **(2)**
*Рассмотрите следующий фрагмент программы.*
```
int x = 7, y = 4;
long double d = 0.25;
cout << (x / y) / d << endl;
cout << (x / d) / y << endl;
long a = 200000, b = 200000;
long long c = 200000;
std::cout << (a * b) * c << std::endl;
std::cout << a * (b * c) << std::endl;
```
*Почему изменения порядка действий приводит
к изменению результата?*
* Скобки определяют порядок действий, а от порядка зависит, к какому типу приводятся операнды на каждом шаге.
*Объясните работу этой программы, используя правила неявного преобразования типов*

1. (x / y) / d
* x / y - оба операнда int. Правила преобразований не применяются, выполняется целочисленное деление
* (x / y) / d - операнды int и long double. По правилам один операнд long double и второй приводится к long double.

2. (x / d) / y
* x / d - int и long double. Также по правилу int приводится к long double.
* (x / d) / y - long double и int. int приводится к long double.

3. (a * b) * c
* a и b оба long.
* (a * b) * c - По правилам long приводится к long long.

4. a * (b * c)
* b * c - По правилам long приводится к long long.
* a * (b * c) также по правилам long приводится к long long.
