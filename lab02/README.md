### Задание 6 **(2)**
*Как можно записывать комментарии на С++?*

* // - однострочный комментарий.
* /* ... */ - многострочный комментарий.

*Какие из приведенных ниже примеров являются синтаксически неверными (вызывают ошибки при трансляции)?
Почему? Как работают синтаксически верные примеры?*

верно синтаксически, но комментарий не будет комментарием внутри строкового литерала
```
cout<<"Hello /* Это комментарий */ world";
```
вывод
```
Hello /* Это комментарий */ world
```

неверно т.к. после однострочного комментария "/*" игнорируется, поэтому нижние строки не считаются комментарием
```
// /*
 Это комментарий
*/
```

неверно т.к. первый "*/" закрывает комментарий, а второй "*/" уже лишний
```
/* Я комментирую программы /* комментарий */ */
```

верно, все многострочные комментарии игнорируются после "//"
```
// Я комментирую программы /* комментарий */  
```

неверно т.к. первый "*/" закрывает комментарий, а второй "*/" лишний
```
/* Я комментирую свои программы
// Это комментарий до конца строки */
*/
```

### Задание 7 **(4)**
*Найдите в стандарте С++*

[http://www.open-std.org/jtc1/sc22/wg21/docs/papers/2017/n4659.pdf]

*в приложении* **A.5** *формальные синтаксические правила для 
инструкций циклов* **iteration-statement.** *Опишите на естественном языке каждую строчку
из этих правил. Для каждой строчки из правила приведите короткий пример фрагмента программы,
которая построена по этому правилу.*

**Формат ответа.**

*Как видно из правил, есть ... (указать число) инструкции циклов.
Первый вид "--- цикл ...(название), который сответсвует строке правила*

*... (переписать строку из правила)*

* Формат записи (по правилу): ключевое слово* **<<while>>**, *в круглых скобках условие* **<<condition>>**,  
*далее инструкция* <<**statement**>>.

*Пример фрагмента программы.*
```
int x = 1;
while (x<1000) {
  cout << x;
  x *= 2;
}
```
#### Ответ
Как видно из правил, есть 4 инструкции циклов.

1. Первый вид - цикл while который соответствует строке правила
while ( condition ) statement

Ключевое слово while, в круглых скобках условие condition, далее инструкция statement.
```
int x = 1;
while (x < 500) {
  cout << x;
  x *= 4;
}
```
2. Второй вид - цикл do-while который соответствует строке правила do statement while ( expression ) ;

Ключевое слово do, далее инструкция statement, затем ключевое слово while, в круглых скобках выражение expression, затем ;
```
int x = 1;
do {
  cout << x;
  x *= 4;
} while (x < 500);
```
3. Третий вид - цикл for который соответствует строке правила for ( init-statement condition_opt ; expression_opt ) statement

Ключевое слово for, в круглых скобках: инициализация init-statement, необязательное условие condition_opt, ;, необязательное выражение expression_opt, ;, затем инструкция statement
```
for (int i = 0; i < 100; i++) {
  cout << i;
}
```
4. Четвёртый вид - цикл for который соответствует строке правила for ( for-range-declaration : for-range-initializer ) statement

Ключевое слово for, в круглых скобках объявление for-range-declaration, :, инициализатор for-range-initializer, затем инструкция statement
```
int a[] = {1, 2, 3};
for (int x : a) {
  cout << x;
}
```
