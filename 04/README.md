### Задание 3 **(2)**
*Объясните работу фрагмента программы на С++. В ходе объяснения следует использовать таблицу кодов символов.*
```
char a = 'a';
a = a + 10;
std::cout << a;
a = a + 250;
std::cout << a;
```

char a = 'a' — код символа 'a' = 97 (0x61).
a = a + 10 → 97 + 10 = 107. Код 107 = символ 'k'. Вывод: k
a = a + 250 → 107 + 250 = 357.
Тип char — 1 байт (8 бит), диапазон обычно от −128 до 127 (знаковый). 357 выходит за границы. Арифметика идёт по модулю 2⁸ = 256:
357 mod 256 = 101
Код 101 = символ 'e'. Вывод: e
Итоговый вывод программы: ke
