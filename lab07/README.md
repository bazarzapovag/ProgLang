### Задание 1 **(2)**
*Оцените работу следующих фрагментов программ. Какие из них обладают неоднозначным поведением? Почему?*
```
int x=10, y=3;
std::cout << std::min(x=15, x+y);
```
Поведение неопределённое

Порядок вычисления аргументов функции не специфицирован. Компилятор может сначала вычислить x=15, а потом x+y (получив 15+3=18), либо наоборот — сначала x+y (получив 10+3=13), а потом x=15.

```
int x=10, y=3;
x=15, y+=x, x+=y;
```

Поведение определённое.

Оператор **,** вводит точку следования. левый операнд вычисляется полностью, затем правый. Сначала x=15, затем y+=15 (y стал 18), затем x+=18 (x стал 33).

```
int x=10, y=9;
if (x>y++ && y++>9)
  cout << "yes" << endl;
cout << y;
```

Поведение определённое.

Оператор **&&** гарантирует точку следования после вычисления левого операнда. Сначала проверяется 10 > 9 (y становится 10), усл. истинно. Затем проверяется 10 > 9 (y становится 11), усл. истинно. Выведется yes, затем 11.

### Задание 5 **(2)**

*Программисты на Python для обмена значений двух переменных часто пишут строку*
```
a,b = b,a
```
*Проверьте, будет ли аналогичная строка на С++ (с точкой с запятой в конце) являться синтаксически
правильной? Будет ли она обменивать значения переменных? Как в языке С++ вычисляется это выражение?*

Строка **a, b = b, a;** на C++ не обменивает значения.

Она интерпретируется как: **a, (b = b), a;**

Потому что оператор **,** имеет самый низкий приоритет, а присваивание **=** выше. Выражение b = b самоприсваивание, а **a** в начале и в конце просто вычисляется и отбрасывается.

### Задание 7 **(2)**

*Как работает следующая программа? Как зависит результат от исходного значения?*
```
int x;
std::cin >> x;
x-->0 && x-->0 && x-->0 && x-->0 && x-->0;
std::cout << x;
```

Здесь --> постфиксный декремент x-- и сравнение > 0 .

Программа вводит x и выполняет до пяти проверок x-- > 0. После каждой проверки x уменьшается на 1, даже если сравнение ложно.

* Если x больше 4х то выполнятся все 5 проверок и x уменьшится на 5.
* Если x = 3: первая проверка 3 > 0 (x=2), вторая 2 > 0 (x=1), третья 1 > 0 (x=0), четвёртая 0 > 0 ложно (x=-1), цепочка прерывается. Итог: x = -1.
* Если x отрицательное то первая проверка ложна но x всё равно уменьшается на 1.
